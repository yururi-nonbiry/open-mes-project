# 主要機能とモジュール

open-mes-project は中小規模工場の製造現場DX化を支援するため、製造実行に必要な複数の機能モジュールをオールインワンで提供します
([prtimes.jp](https://prtimes.jp/main/html/rd/p/000000001.000134589.html))。主な機能領域と役割は以下のとおりです。

- **生産管理 (Production)**：作業指示の発行や製造オーダーの管理、作業進捗の把握を行います
  ([prtimes.jp](https://prtimes.jp/main/html/rd/p/000000001.000134589.html))。現場の作業者への指示出しから、完了報告、進捗状況の可視化までを一元管理します。また、製品ごとの使用部品構成を管理するBOM（部品表）マスター機能や、複数の生産計画を横断して共通部品の需給を試算する部品供給シミュレーション機能も提供します。

- **在庫管理 (Inventory)**：原材料・部品・製品の入庫、保管、出庫までの一連の在庫管理機能を提供します
  ([min-mes.com](https://min-mes.com/blog/2024-04-19/) [min-mes.com](https://min-mes.com/blog/2024-04-26/))。リアルタイムに在庫数量を把握し、在庫不足や過多を防ぎます。

- **品質管理 (Quality)**：製造品の検査記録を管理・分析し、不良率や品質傾向を可視化します
  ([min-mes.com](https://min-mes.com/blog/2024-04-26/))。品質データの収集・分析によりムダやロスの削減、品質向上を図ります
  ([prtimes.jp](https://prtimes.jp/main/html/rd/p/000000001.000134589.html))。

- **設備管理 (Machine)**：工作機械や生産設備のマスタ情報（設備番号、設置場所等）を管理します。2026年7月時点では設備マスターの管理機能が中心で、稼働ログや保全記録を扱うモデルは未実装です。

- **マスタ管理 (Master)**：製造に関わる各種マスタデータを管理します。品目（製品/材料）、サプライヤー、倉庫・倉庫内ロケーション、顧客、ワークセンター、標準単価、使用部品構成（BOM）などを保持し、他の機能が参照する基本データとなります。コード上は`master`アプリケーションとして実装されています。

- **ユーザー管理 (Users)**：システムにログインするユーザーアカウントの管理機能です。ユーザーの新規登録（管理者による作成）、権限ロールの付与、JWTによる認証（ログイン/ログアウト）、パスワード有効期限管理などを提供します。ユーザー情報はDjangoの認証機能（`AbstractBaseUser`）を拡張して実装されており、専用のログインID（`custom_id`）でログインします。

- **ベース機能 (Base/Core)**：共通設定やCSVインポート設定、QRコード読み取り時のアクション定義、非同期タスク（Celery連携）の状態管理など、他の全機能にまたがる基盤的な機能を提供します。他モジュールから参照される土台となります。

各モジュールはDjangoのアプリケーションとして実装されており、それぞれにモデル・REST APIビュー（多くは`rest_views.py`、baseは`api.py`、usersは`rest.py`）・マイグレーションが定義されています。画面はDjangoテンプレートではなく、対応するReactフロントエンド（`frontend/src/pages/`配下の各モジュールディレクトリ）から実装されています。バックエンド起動時にマイグレーションが自動適用され、データベースに対応するテーブル群が作成されます（詳細は[アーキテクチャ概要](./01_architecture.md)を参照）。モジュール間では外部キー等で関連づけが行われ、例えば生産管理で定義した製造オーダーと在庫管理の在庫テーブルを関連付けて、製造で使用した部材の在庫引当を行う、といった連携動作が可能です。さらに品質管理から生産実績や在庫品の品質データを参照したり、設備管理から稼働データを取得して生産計画にフィードバックするなど、モジュール間でデータをやり取りすることで製造現場全体を最適化します
([prtimes.jp](https://prtimes.jp/main/html/rd/p/000000001.000134589.html))。各機能はオープンソースで公開されているため、自社ニーズに合わせてコードを自由に改変・拡張でき、既存システムとの連携も柔軟に対応可能です
([prtimes.jp](https://prtimes.jp/main/html/rd/p/000000001.000134589.html))。
